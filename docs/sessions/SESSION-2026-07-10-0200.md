## Bugs Fixed

1. **`event-risk-filter.js:57` — an absent VIX read as a calm one.** `Number(i.vix) || 0` mapped
   `null`, `undefined`, `NaN` and `0` all onto `0`, below every threshold. So a Yahoo outage silently
   disarmed the gate on new premium selling — exactly when volatility was least knowable. India VIX is
   never 0; a zero means *no reading*. Now: `REDUCE`, `sizeScale 0.5`, `vixUnknown: true`, `vix: null`,
   and the reason names the missing evidence. Same policy as the unreadable-calendar precedent in the
   same file. **A HIGH-impact event still BLOCKs, and two unknowns compound rather than cancel.**
2. **`test/perf-budget.test.js` — a ratchet that could not see what it guarded.** Its scan matched only
   the `fs.` and `_fs.` receivers, so it never saw `fs2.`, `_fs2.`, `_persistFs.` or `_sigFs.` —
   `server.js` uses all four. It reported **4 raw writes where there were 10**, and passed on the
   undercount. Fixed to match any receiver; the same bug was in `scripts/perf-report.js`.
